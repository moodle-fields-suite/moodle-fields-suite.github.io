Por que usar

Dados estruturados, sem gambiarra

Sem a suíte, dado estruturado vira dezenas de campos de texto, ou fica fora do Moodle. Com ela, cada entidade ganha os campos de que precisa, com validação e permissões.

🧩

JSON com editor visual

Árvore, código com realce, formulário e visualização. O servidor só grava JSON válido, dentro do tamanho definido para o campo.

🗂️

Campos onde o Moodle não tem

Categorias de curso hoje; competências, planos de aprendizagem e emblemas em seguida. Todos os tipos de campo instalados no site.

🔒

Visibilidade e permissões

Cada campo pode ser visível para todos, só para quem edita ou para ninguém, e campos bloqueados exigem permissão própria.

🔌

Pronto para integrações

Web services de leitura devolvem só o que o usuário pode ver. Valores guardados de forma canônica e previsível.

🛡️

Seguro por padrão

Valores sempre escapados na exibição, validação em todos os caminhos de gravação (formulário, upload e web service) e Privacy API.

✅

Testado e documentado

CI com Moodle 4.5 e 5.3, PostgreSQL e MariaDB, testes PHPUnit e documentação em português e inglês.

Instalação

Instale em poucos minutos

Cada plugin é instalado como qualquer outro do Moodle, pelo ZIP da release.

  1. Escolha o que usar: o tipo de campo JSON para perfil (profilefield_json) ou para campos personalizados (customfield_json), e as áreas novas, como tool_categorycustomfields.
  2. Baixe o ZIP na página Releases de cada repositório.
  3. Instale em Administração do site > Plugins > Instalar plugins e conclua o upgrade.
  4. Crie os campos: perfil em Usuários > Contas > Campos de perfil; cursos, coortes e grupos nos campos personalizados de cada um; categorias em Cursos > Campos personalizados de categoria.

Requisitos: Moodle 4.5 LTS ou 5.3 LTS. Estado atual: beta, em revisão no Moodle Marketplace.
