The fields your Moodle was missing

Keep structured data where you need it: a JSON document with a visual editor in profiles, courses, cohorts or groups, and custom fields for course categories and, soon, competencies and badges.

Community project, unofficial: not affiliated with Moodle HQ.

Why use it

Structured data, no workarounds

Without the suite, structured data turns into dozens of text fields, or stays outside Moodle. With it, every entity gets the fields it needs, with validation and permissions.

🧩

JSON with a visual editor

Tree, highlighted code, form and view modes. The server only saves valid JSON within the size set for the field.

🗂️

Fields where Moodle has none

Course categories today; competencies, learning plans and badges next. Every field type installed on the site.

🔒

Visibility and permissions

Each field can be visible to everyone, only to editors or to nobody, and locked fields need their own capability.

🔌

Ready for integrations

Read web services return only what the user can see. Values are stored in a canonical, predictable form.

🛡️

Secure by default

Values always escaped on display, validation on every save path (form, upload and web service) and the Privacy API.

✅

Tested and documented

CI on Moodle 4.5 and 5.3 with PostgreSQL and MariaDB, PHPUnit tests and documentation in English and Portuguese.

Installation

Install in a few minutes

Each plugin installs like any other Moodle plugin, from the release ZIP.

  1. Choose what to use: the JSON field type for profiles (profilefield_json) or for custom fields (customfield_json), and the new areas, such as tool_categorycustomfields.
  2. Download the ZIP from the Releases page of each repository.
  3. Install at Site administration > Plugins > Install plugins and finish the upgrade.
  4. Create the fields: profiles at Users > Accounts > User profile fields; courses, cohorts and groups in their custom fields pages; categories at Courses > Category custom fields.

Requirements: Moodle 4.5 LTS or 5.3 LTS. Current state: beta, under review in the Moodle Marketplace.
